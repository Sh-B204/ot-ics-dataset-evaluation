# ICS Intrusion Detection Benchmark

Evaluation code for supervised and unsupervised intrusion/anomaly detection
on an ICS/OT network-flow dataset. This repository contains the preprocessing
pipeline, model training/evaluation code, robustness and ablation studies,
and the figure/table generation used to produce the results reported in the
accompanying paper.

## Overview

The pipeline takes raw ICS flow data, builds two processed benchmark
variants (full-feature and time-ablated), and evaluates three supervised
models (Random Forest, XGBoost, MLP) and two unsupervised models (Isolation
Forest, Stacked Autoencoder) on binary attack detection and multiclass
attack-type classification. On top of the primary evaluation, the repo
includes a hyperparameter study, a repeated-seed robustness study, a
full-feature vs. time-ablated comparison, and unsupervised robustness
evaluation, plus the scripts that generate the paper's final figures and
tables from the resulting predictions and metrics.

the original experiments, since a lot of code refers to them by name — only
their parent location moved (from inside the old evaluation folder to the
repo root).

## Dataset

The raw dataset is **not included**; see [`data/README.md`](data/README.md)
for where to download it and where to place it. If you already have the
processed `with-time` / `no_time` benchmark folders, drop them into
`data/processed/` and everything else works unchanged.

## Installation

```bash
git clone <REPOSITORY_URL>
cd ics-intrusion-detection-benchmark
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

The evaluation code is a plain Python package under `src/ics_ids`. Rather
than installing it, add `src/` to `PYTHONPATH` before running anything:

```bash
export PYTHONPATH=$(pwd)/src        # Windows (PowerShell): $env:PYTHONPATH = "$PWD\src"
```

## Reproducing preprocessing

```bash
python preprocessing/preprocess_ics_flow_dataset.py
```

Generates `data/processed/with-time/` and `data/processed/no_time/`.

## Reproducing the primary evaluation

Each supervised/unsupervised model can be run directly; by default it trains
and evaluates on the time-ablated (`no_time`) benchmark and writes metrics,
predictions, a confusion-matrix figure, and (where applicable) a trained
model to `results/`:

```bash
python -m ics_ids.models.supervised.random_forest
python -m ics_ids.models.supervised.xgboost_model
python -m ics_ids.models.supervised.mlp_model
python -m ics_ids.models.unsupervised.isolation_forest
python -m ics_ids.models.unsupervised.stacked_autoencoder
```

Each module also exposes a `run(data_dir=..., run_name=...)` function so it
can be called against `config.WITH_TIME_DATA_DIR` with a different
`run_name` tag to produce the with-time variant of the same evaluation (this
is how the `*_with_time_ablation_*` result files were produced).

## Reproducing individual experiment groups

```bash
python -m ics_ids.evaluation.dataset_diagnostics       # class counts, feature counts, etc.
python -m ics_ids.experiments.run_hyperparameter_study  # hyperparameter search
python -m ics_ids.experiments.run_repeated_seeds         # supervised repeated-seed robustness
python -m ics_ids.experiments.run_time_ablation           # tuned full-feature vs time-ablated comparison
python -m ics_ids.experiments.run_unsupervised_repeated_seeds  # IF/SAE robustness
```

All four accept `--help` for their available options (model/task/seed
subsets, `--plot-only` to regenerate outputs from existing CSVs, etc.).

## Reproducing the final evaluation batch

```bash
python scripts/run_all.py
```

Runs the repeated-seed study, the tuned time-ablation comparison, and final
figure generation in sequence. Useful flags:

- `--plot-only` — regenerate figures/tables from existing CSVs without retraining
- `--skip-repeated-seeds`, `--skip-time-ablation`, `--skip-visualization`
- `--include-legacy` — also regenerate the earlier fixed-baseline figures
- `--include-unsupervised` — also regenerate the unsupervised ROC/PR figure
- `--models`, `--tasks`, `--seeds` — restrict to a subset

## Regenerating figures only

```bash
python -m ics_ids.visualization.visualization --final-only
```

Reads existing metrics/predictions and regenerates the final paper figures
(ROC/PR curves, best multiclass confusion matrix, repeated-seed stability,
time-ablation performance drop) without retraining anything. Add
`--include-legacy` and/or `--include-unsupervised` for the older/unsupervised
figures.

## Outputs

- `results/models/` — trained model artifacts (gitignored; regenerate by
  running the evaluation scripts above)
- `results/metrics/`, `results/predictions/` — primary evaluation outputs
- `results/hyperparameter_study/`, `results/robustness/`,
  `results/unsupervised_robustness/`, `results/time_ablation/`,
  `results/time_ablation_tuned/`, `results/dataset_diagnostics/` — outputs of
  each experiment group
- `results/figures/` — all generated figures, with the final paper figures
  under `results/figures/supervised_results/`

## Reproducibility

Seeds used throughout: `42, 7, 21, 100, 2026` (`config.SEEDS`), with `42` as
the default single-run seed (`config.RANDOM_STATE`). These are fixed in code
and unchanged from the original experiments. Full determinism is not
guaranteed for the neural-network models (MLP, Stacked Autoencoder) due to
standard floating-point/parallelism nondeterminism in TensorFlow.

## Models evaluated

- **Supervised**: Random Forest, XGBoost, MLP — binary attack detection and
  multiclass attack-type classification
- **Unsupervised**: Isolation Forest, Stacked Autoencoder — binary anomaly
  detection, trained on normal traffic only
